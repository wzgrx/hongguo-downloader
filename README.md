## 📖 软件简介

本软件是一款专为**红果短剧（番茄小说短剧频道/novelread系）**打造的高效 Windows 桌面级全集批量解析与下载工具。

传统抓取方式只能录屏或抓取到分片加密文件，本工具采用 **Electron + React + Node.js** 现代桌面架构，内置字节系短剧 API 逆向协议与 **CENC-AES-CTR 原生流式解密引擎**，可一键批量解析整部短剧的所有集数，并在下载过程中自动解密生成无水印、高码率的标准 MP4 原画视频。

## 🌟 全部具体功能清单

### 一、 🎬 智能短剧解析与元数据提取

1. **多格式输入自动识别**：
   - 支持直接粘贴红果短剧 App 的**分享链接**；
   - 支持包含引导文案和特殊口令的**长文本自动清洗提取**；
   - 支持直接输入短剧的 **`series_id`**（纯数字剧集 ID）秒级解析。
2. **完整剧集元数据解析**：
   - 自动拉取短剧官方全名、高清竖版封面海报、总集数；
   - 自动获取每集的真实集数序号（如第 1 集、第 2 集……第 100 集）及其分集官方标题；
   - 自动映射每集的唯一视频识别码 (`vid`) 与播放源配置。

1. **一键全局选集**：
   - **全选**：解析完成后默认全选整部剧集；
   - **反选**：一键将已选集数与未选集数状态互换；
   - **清空**：一键取消全部选中状态。
2. **高频快捷选集预设**：
   - ⚡ **前 10 集**：快速抓取试看引流钩子集；
   - ⚡ **前 30 集**：批量提取前半部分剧情高潮素材；
   - ⚡ **后 30 集**：快速抓取大结局与完结反转部分。
3. **强大的复合区间语法筛选**：
   - 支持在输入框内自定义输入集数范围，瞬间批量打钩：
     - 单区间示例：`1-50`（自动选中 1 到 50 集）；
     - 多区间复合示例：`1-10, 25, 30-45`；
     - 离散集数示例：`1, 3, 5, 7, 9`。
4. **单集卡片式精细挑选**：
   - 页面以网格徽章卡片展示所有分集，支持随时点击任意单集进行单独勾选/取消。

### 三、 🔐 原生底层解密与高速下载引擎

1. **spade_a 密钥派生与 CENC-AES-CTR 实时解密**：
   - 针对红果短剧平台的视频加密保护机制，软件在 Node.js 原生底层内置了专用密钥派生算法；
   - 在数据流写入本地的同时执行 **CENC-AES-CTR 原生流式解密**，直接输出标准非加密的 MP4 视频文件，画质清晰度与官方客户端原画 100% 一致，无需二次转码。
2. **可靠的分片防损机制**：
   - 下载过程中采用 `.part` 临时文件机制，只有完整拉取并解密成功后才重命名为最终 `.mp4` 文件，彻底防止中途断网产生残缺损坏文件。
3. **多并发线程池调节**：
   - 支持自定义设置 1 ~ 10 线程并行下载；
   - 智能队列排队机制，下载完成后自动顺延启动下一集。

   - 支持 1~10 个任务同时下载，在设置里调整「最大并发下载数」，保存后立即生效。

## 🛠️ 开发者：本地运行与源码构建

### 环境要求
- 操作系统：Windows 10 / 11 x64
- Node.js：>= 18.0.0 (推荐 20.x 或 22.x x64)
- npm：>= 9.0.0

### 本地开发启动

```powershell
# 1. 克隆本仓库
git clone https://github.com/327044572/hongguo-downloader.git
cd hongguo-downloader

# 2. 安装项目依赖
npm install

# 3. 启动开发模式（同时运行 Vite 前端和 Electron 客户端）
npm run dev
```

### 生产打包构建

```powershell
# 1) 准备内置 ffmpeg（约 88MB，不入库，只需执行一次）
node scripts/setup-ffmpeg.js

# 2) Windows 上若未以管理员身份运行，先执行一次（见下方说明）
node scripts/setup-winCodeSign.js

# 3) 按需选择打包方式
npm run build             # NSIS 安装包（默认）
npm run build:zip         # 绿色版 zip（推荐用于分发）
npm run build:dir         # 仅免安装目录 dist/win-unpacked
npm run build:portable    # 便携单文件 exe
npm run build:installer   # 同 build
```

#### 三种产物的区别

| 产物 | 大小 | 说明 |
|---|---|---|
| `红果短剧下载器-Setup-1.0.0.exe` | ~116 MB | **NSIS 安装包**：双击安装，创建桌面/开始菜单快捷方式，可改安装目录，可从控制面板卸载 |
| `红果短剧下载器-1.0.0-win-x64.zip` | ~158 MB | **绿色版 zip**：解压即用，解压后是一个完整文件夹，双击里面的 exe 运行；启动最快，最适合分发 |
| `红果短剧下载器-1.0.0-便携版.exe` | ~108 MB | **便携单文件**：双击直接运行，免安装；但每次启动都要自解压到临时目录，启动稍慢 |
| `win-unpacked/` | ~421 MB | 未压缩的绿色版目录（zip 的来源） |

> **分发建议**：发给别人用 `build:zip` 出的 zip —— 解压后目录结构完整、启动最快，
> 也避免了「便携单文件版每次自解压」和「杀软误报自解压行为」的问题。

> zip 内已套好顶层文件夹 `红果短剧下载器-1.0.0/`，用户解压不会把文件散落一地。

#### Windows 打包常见问题：winCodeSign 解压失败

`winCodeSign-2.6.0.7z` 内含两个 **macOS** 用的符号链接
（`darwin/10.12/lib/libcrypto.dylib`、`libssl.dylib`）。Windows 上创建符号链接需要
管理员权限或开启「开发者模式」，普通权限下 7-Zip 会以退出码 2 结束，electron-builder
反复重试后中止打包（报错 `Cannot create symbolic link`）。

两个解决办法，任选其一：

1. **推荐**：执行一次 `node scripts/setup-winCodeSign.js`，把该压缩包解压到固定目录
   `.eb-cache/winCodeSign/winCodeSign-2.6.0`，再打包时带上环境变量：
   ```powershell
   $env:DSH_WINCODESIGN_DIR='E:\hongguo_dd\.eb-cache\winCodeSign\winCodeSign-2.6.0'
   npm run build
   ```
   （macOS 符号链接缺失不影响 Windows 打包，用到的只有 `windows-10/` 与 `rcedit-*.exe`。）

2. 以管理员身份运行终端，或开启 Windows「开发者模式」后直接 `npm run build`。
